# A concise introduction 
This is a C programming course assignment that I completed during my first year of university. 
Although its syntax is simple and its content is relatively rudimentary, it nevertheless represents the best code I was capable of writing at the time. 
Its overall structure is modular; however, in accordance with the instructor’s assignment requirements, I did not create or organize separate header files, and instead implemented the project within a single source file. 
The project implements a console-based calendar display with switching among three languages, although it is admittedly still quite unpolished.
